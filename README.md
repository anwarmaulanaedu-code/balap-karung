# balap-karung
Balap Karung 2D adalah game balap tradisional bernuansa 17 Agustus-an yang dibuat khusus untuk merayakan HUT RI ke-81. Pemain akan adu cepat untuk mencapai garis finis dalam balap karung. Game ini bisa dimainkan sendirian melawan komputer (1 Player) atau bermain berdua (Lokal 2 Player) menggunakan keyboard maupun gamepad.
